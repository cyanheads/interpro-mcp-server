# 0.2.0 — 2026-10-28

## Added

- **`interpro_get_structure_domains`** maps InterPro and member-signature matches onto a PDB entry's protein chains, with chain `start`/`end`, author `auth_start`/`auth_end`, and UniProt positions kept as upstream writes them. InterPro nests at most 20 chain records per match; set `chain` to read one chain completely ([#11](https://github.com/cyanheads/interpro-mcp-server/issues/11)).
- **`interpro_scan_sequence`** returns domain matches for one raw protein sequence: precalculated Matches API results when the sequence is in UniParc, otherwise an InterProScan 6 job through the EBI Job Dispatcher. **`interpro_get_scan_result`** reads that job by `jobId` for seven days ([#12](https://github.com/cyanheads/interpro-mcp-server/issues/12)).
- **`INTERPRO_SCAN_EMAIL`** is the optional contact address the Job Dispatcher requires to start a job; unset, sequences without precalculated matches fail as `scan_not_configured`. At most 25 jobs run at once, and a submission past that fails as `rate_limited`.
- **`interpro_list_reference`** `accession_patterns` lists the `pdb` and `pdb_chain` identifier patterns.
- **`interpro-guide`** is a published agent skill in `skills/` covering identifier chains, gates, and numbering. The server serves it with `createApp({ skills: 'skills' })`; the npm package and Docker image include it.

## Changed

- **`interpro_find_proteins_by_domain`** accepts `proteomeId` (a UniProt proteome accession such as `UP000000625`) and keeps the proteome records upstream returns; `taxonId` still applies, including its `9606` default ([#23](https://github.com/cyanheads/interpro-mcp-server/issues/23)).
- **`protein.proteome`** is a typed field on protein maps, the source of `proteomeId` values ([#23](https://github.com/cyanheads/interpro-mcp-server/issues/23)).
- **`interpro_get_protein_domains`** `scannedMatches` description now says a complete walk can cover a different number than `totalMatches`.
- **The shared HTTP adapter** sends POST bodies and accepts the Matches API and `iprscan6` path prefixes on the fixed EBI origin.
- **Packaging metadata** declares `INTERPRO_SCAN_EMAIL` in `server.json`, `manifest.json`, and the plugin manifests; the repo gains the Agent Plugins `plugin.json` and `mcp.json` pair.
- **Development guidance and packaging checks** are synchronized with the adopted framework.
