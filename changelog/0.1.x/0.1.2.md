# 0.1.2 — 2026-10-24

## Added

- **`interpro_get_entry`** adds readable `entry.descriptionText` with paragraph, list, and table boundaries alongside raw descriptions and annotation flags. ([#15](https://github.com/cyanheads/interpro-mcp-server/issues/15))
- **`interpro_find_proteins_by_domain`** accepts optional `isFragment`, returns native fragment annotations on every page, and binds explicit selections to cursors; missing/null status remains unknown, and false does not establish sequence completeness. ([#16](https://github.com/cyanheads/interpro-mcp-server/issues/16))

## Changed

- **Paged reads** clamp oversized positive integer limits to 100 entries/members or 50 proteins, with requested/effective disclosure composed with continuation and omission notices. ([#14](https://github.com/cyanheads/interpro-mcp-server/issues/14))
- **Hosted access** is documented in the README and advertised through MCP Registry remote metadata.

## Fixed

- **`interpro_search_entries`** rejects member-database GO filters before requesting data, with recovery through InterPro `member_databases` or member searches using `integratedInto`. ([#13](https://github.com/cyanheads/interpro-mcp-server/issues/13))

## Dependencies

- Add **`htmlparser2` ^12.0.0** for HTML fragment tokenization and entity decoding.
- **`ignore`** ^7.0.12 → ^7.0.13.
- **Bun** 1.4.3 → 1.4.4 in package-manager metadata and Docker images.
