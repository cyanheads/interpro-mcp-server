# 0.1.3 — 2026-10-24

## Changed

- **`interpro_get_entry`** accepts `sections` to select named metadata while retaining core and unknown fields, and explicit `overlapLimit`/`overlapOffset` paging of whole overlap records with continuation guidance ([#19](https://github.com/cyanheads/interpro-mcp-server/issues/19)).
- **`interpro_get_protein_domains`** accepts opt-in `includeResidueAnnotations`, traversing complete residue rules after matches and requested extra features; coverage distinguishes an unreached stage from an empty selection ([#20](https://github.com/cyanheads/interpro-mcp-server/issues/20)).
- **`interpro_find_proteins_by_domain`** accepts `architectureId` for native Pfam architecture filtering and reports unavailable entry/taxon details explicitly ([#21](https://github.com/cyanheads/interpro-mcp-server/issues/21)).
- **Output links and images** use the framework's Markdown helpers for HTTP(S), preserving validated data-image thumbnails.
- **Development guidance and audit checks** are synchronized with the adopted framework; hosted setup documents each client's configuration shape.

## Fixed

- **`interpro_search_entries`** rejects simultaneous `goTerm` and `goCategory` before network access, with typed recovery naming the supported standalone filters ([#18](https://github.com/cyanheads/interpro-mcp-server/issues/18)).

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.13.15 → ^0.13.16.
- `@biomejs/biome` 2.5.15 → 2.6.2.
