# 0.4.0 — 2026-11-21

## Added

- **`interpro_find_architectures`** finds Pfam domain architectures from domain combinations and returns IDs for protein searches. ([#38](https://github.com/cyanheads/interpro-mcp-server/issues/38))
- **`interpro_find_structures`** filters by experimental method, maximum resolution, and organism for entry searches. ([#37](https://github.com/cyanheads/interpro-mcp-server/issues/37))

## Changed

- **`interpro_get_clan`** reuses cached set details across member and relationship pages. ([#32](https://github.com/cyanheads/interpro-mcp-server/issues/32))

## Fixed

- **`interpro_get_structure_domains`** reports available UniProt chain mappings when InterPro has mapped proteins but no structure annotations. ([#34](https://github.com/cyanheads/interpro-mcp-server/issues/34))
- **`interpro_find_proteins_by_domain`** distinguishes unknown entries, taxa, and proteomes from valid empty intersections and points PANTHER subfamily lookups to their parent families. ([#35](https://github.com/cyanheads/interpro-mcp-server/issues/35))
- **`interpro_get_clan`** distinguishes Pfam and CDD by accession width regardless of letter case. ([#36](https://github.com/cyanheads/interpro-mcp-server/issues/36))
- **`interpro_search_entries`** describes literal substring matching and suggests a distinctive word when a phrase misses. ([#39](https://github.com/cyanheads/interpro-mcp-server/issues/39))
